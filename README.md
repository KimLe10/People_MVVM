# People_MVVM

Small iOS app that fetches a list of people from a REST API, with live search-as-you-type filtering. Practice project for MVVM + Combine.

## Stack

SwiftUI, Combine

## Running it

Open in Xcode, run on a simulator.

## Tests

`People_MVVMTests` covers the success/empty/error states using a fake network service + JSON fixtures, no real network calls.
